# HelloWorld media 1

Unmodified video assets for the HelloWorld technical report website.

GitHub Actions downloads the existing release files, verifies size and SHA256, and publishes them to GitHub Pages. Visitors stream MP4 files directly from Pages. No encoding or resizing is performed.

Published video bytes: 638,328,175. Keep the source release assets as build inputs. To update a video, update its URL, bytes and SHA256 in media-manifest.json and push main.
